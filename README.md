Python Data Cleaner

A simple Python tool to clean CSV files automatically.

Features
- Removes duplicate rows
- Trims extra spaces from headers and values
- Works with Python built-in CSV module
- Saves cleaned data to a new CSV file
- Displays a cleaning summary

Requirements
- Python 3

How to Run
python data_cleaner.py sample.csv

Example Output
Original rows: 5
Cleaned rows: 3
Duplicates removed: 2

Technologies
- Python
- CSV module
